# Loan - La Logo Folder

Place your logo picture files in this folder (`public/logo/`).

### Supported formats & filenames:
- `logo.png` (Recommended: transparent PNG, square or horizontal aspect ratio, e.g. 512x512px)
- `logo.svg`
- `logo.webp`
- `logo.jpg`

The application will automatically load and display your logo picture across the website header, navigation bars, and PDF reports.
