# Malaysian Bank & Lender Logos Repository (`public/banks/`)

This directory contains the official logo files for all licensed Malaysian commercial banks, digital banks, Islamic banks, finance companies, and P2P lending platforms integrated into **Loan - La / CreditFlow AI**.

---

## 📁 How to Update / Replace Bank Logos

You can easily replace any bank logo with your own `.svg` or `.png` file at any time.

### Guidelines:
1. **File Format**: `.svg` (recommended for crisp vector rendering) or `.png` (with transparent background).
2. **Recommended Dimensions**: `128x128px` or `256x256px` square, or `4:3` ratio with transparent background.
3. **Naming Rule**: Keep the exact filename listed in the directory below.
